# RESEARCH/BANGERS — ten sell-first idea tracks

Paper only. Not Mission Winning product code. Not a store. Not traction.

**BANGERS** is a closed set of ten small utilities that ride **iOS 27 / camera / Photos / agent-ops** seams. Each track is a folder with the same **six-file contract**. Sell the offer before writing the capture graph. `paymentUrl` stays empty until a founder wires a real processor they own. Agents never invent a checkout URL.

Overnight runner: [OVERNIGHT_GLM53.md](OVERNIGHT_GLM53.md).

Honesty check:

```bash
node RESEARCH/BANGERS/scripts/verify-contract.mjs
```

This PR owns **04–10** plus this index and the overnight playbook. Tracks **01–03** are sibling frameworks (same contract, other PRs). Links below use the agreed slugs. If a sibling folder is missing on this branch, the row is the contract name — not a claim the six files exist here.

| ClearShot stays parked | Do not call track 02 a live product |
| Builder ≠ Judge | This tree does not self-LGTM |
