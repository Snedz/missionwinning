# RESEARCH/BANGERS/

BANGERS is a closed set of side-bet research tracks. Each track sells a machine, names what must not be built, and leaves a Cursor-ready todo — it does not ship product.

| # | Track | Slug | One line |
|---|-------|------|----------|
| 03 | Token router (gas pipeline) | [token-router-pipeline/](token-router-pipeline/INDEX.md) | Disk-first indie router: health → score → claim → dispatch → receipt. Free-first. `ALLOW_PAID` hatch. M1 caps. No silent paid spend. |

Tracks 01 and 02 are not in this tree yet. Do not invent them here.

## File contract (every track)

| File | Owns |
|------|------|
| `FRAMEWORK.md` | Metaphor, laws, pipeline, caps, kill |
| `SELL_FIRST.md` | Who pays, offer, objections — before any code |
| `BUILD_LATER.md` | Explicit deferrals and why |
| `HOW_IT_GETS_DONE.md` | Disk layout, stage contracts, test falsifiers |
| `CURSOR_TODO.md` | Agent tickets, ordered, one concern each |
| `SOURCES.md` | URLs + retrieval date + what was taken |
| `INDUSTRY_LANDSCAPE.md` | Named infra map (AI gateways, not fitness apps) |
| `*.schema.yaml` | Proposed on-disk contracts (paper until commissioned) |

## Classification

PUBLIC. AI infrastructure names are allowed. Consumer fitness product names are still INTERNAL (`ops/intel/`). No keys, no live spend figures invented as traction.
