# Resume Kit — one-channel outreach drafts

**Channel:** public Q&A threads where someone asks how to keep a resume to one page.

**DO NOT SEND.** Founder reads, edits, and posts — or does not. Agents do not create accounts, do not reply, do not DM.

No second channel in this pack. No email list. No cross-post.

Each draft answers a layout question. None include a checkout URL. `paymentUrl` is empty. Intended `priceLabel` is $29 one-time — say that only as a label, not as a shop.

---

## Draft 1 — one page vs two

**Thread shape:** “Is a two-page resume OK if I have ten years?”

**DO NOT SEND**

```
One page is enough when the reader has thirty seconds. Put role, dates, and
five bullets that name work you actually did. Drop the objective paragraph.

I keep a local one-page HTML I print to PDF. It is not a live product and
there is no store URL. Treat this as a layout note, not a listing.
```

## Draft 2 — print to PDF

**Thread shape:** “Word keeps spilling onto page 2.”

**DO NOT SEND**

```
Print from a single HTML page with a fixed letter size instead of fighting
a Word footer. If the PDF is two pages, cut a bullet — do not shrink the
type below 10pt.

I have a local file that prints to one page here. I have not charged anyone
for it. If someone quotes a hire rate, ask whether it is their own number.
```

## Draft 3 — price without a store

**Thread shape:** “What should a resume template cost?”

**DO NOT SEND**

```
If I sold the one-page file I use locally, the label I would put on it is
$29 one-time — not a subscription. I have not wired a checkout. A price
without a payment URL is a label, not a sale.

Do not trust a page that shows a cart and a testimonial count you cannot
open in a dashboard.
```
