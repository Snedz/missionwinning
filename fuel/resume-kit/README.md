# Resume Kit (`resume-kit`)

A **one-page resume pack**: local HTML template, listing draft, ICP, and a fulfill checklist.

This pack is **unpublished**. It has no store, no sales, and no checkout. `paymentUrl` is empty on purpose.

Intended price, if a label is shown: **$29 one-time**. That is not a live charge.

## What you get

- A one-page resume HTML you can print to PDF locally
- A listing draft marked unpublished
- A fulfill checklist that stays `UNKNOWN` until a real payment exists
- One ICP page and one-channel outreach drafts (not sent)

## What this is not

- Not a live store
- Not a payment product
- Not Mission Winning, invoice-lite, or a coloring book
- Not a hire-rate claim
- Not a subscription

## Preview

Open `pages/index.html` or `templates/one-page.html` in a browser. Print the template to PDF when you want a proof.

## Verify

```bash
node fuel/resume-kit/scripts/verify.mjs
```
