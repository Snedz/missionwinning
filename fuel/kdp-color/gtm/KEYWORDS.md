# Open Plate — keyword notes

These are **working notes** for the seven KDP backend slots already drafted in `listing.md`. They are not search-volume research. No count in this file is a measured query volume.

Do not paste a “competitor ASIN hijack” list. Do not name other consumer fitness apps.

## Slots (same seven as the listing draft)

| # | Slot | Why it is here |
|---|------|----------------|
| 1 | coloring book color interior | Names the print type buyers filter for |
| 2 | geometric coloring pages | Matches plates 01, 05, 08, 11 |
| 3 | botanical line art coloring | Matches plates 02, 06, 12 |
| 4 | architectural window coloring | Matches plates 03, 07 |
| 5 | adult coloring paperback | Age band + binding, not a children’s character book |
| 6 | 8.5 x 11 coloring book | Trim people type when they want a large page |
| 7 | original plates no characters | States the IP posture in the slot itself |

Each slot must stay ≤ 50 characters. Count in the KDP form, not here.

## What we did not put in a slot

- A city or year (“2026”) as a fake freshness trick
- Another publisher’s series name
- “low content” as a boast
- A price or a store URL

## When to rewrite

After a real ASIN exists, replace this page with terms from **that** book’s search term report — not from a course spreadsheet. Until upload day, these seven stay a draft.
