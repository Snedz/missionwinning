# Open Plate (`kdp-color`)

A **color-interior starter** for a paperback coloring book on Amazon KDP.

This pack is **unpublished**. It has no ASIN, no ISBN, no sales, and no checkout. `paymentUrl` is empty on purpose.

## What you get

- 12 original black-line plates (SVG)
- A 24-page 8.5×11 assembly that hits the KDP paperback minimum **without repeating a plate**
- A listing draft marked unpublished
- Export notes for bleed, color ink, and upload
- One ICP page and one-channel outreach drafts (not sent)

## What this is not

- Not a live Amazon listing
- Not a cover / spine file
- Not a payment product
- Not Mission Winning, resume-kit, or invoice-lite
- Not a get-rich listing kit or a rank claim

## Preview

Open `pages/index.html` or `interiors/book.html` in a browser. Print `book.html` to PDF when you want a proof — see `export/NOTES.md`.
