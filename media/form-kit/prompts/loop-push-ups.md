# Loop director — push-ups

```
FORMAT
6s · 1 continuous shot · 1:1 · silent · loopable

ACTIVE REFERENCES
Input still ONLY. Exact person/clothes.

CAMERA LOCK
Tripod locked. Zero pan/tilt/zoom/reframe/cut/Dutch.

ACTION TIMING
0–1s hold plank · 1–2.5s lower · 2.5–4s press lockout · 4–5.5s second rep · 5.5–6s settle

PHYSICS
Bodyweight only. Head always in frame.

NEGATIVES
Camera move, bar, cropped head, text, logos.
```
