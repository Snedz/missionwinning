# Loop director — kettlebell-swing

```
FORMAT
6s · 1 continuous shot · 1:1 · silent · loopable

ACTIVE REFERENCES
Input still ONLY. One KB at float top.

CAMERA LOCK
Tripod locked. Zero camera motion.

ACTION TIMING
0–1s float top · 1–2.5s hinge down · 2.5–4.5s hip snap to float · 4.5–6s settle

PHYSICS
KB always OUTSIDE body — never through hips/torso. Head always in frame.

NEGATIVES
Bar through body, camera move, cropped head, second KB, text, logos.
```
