# Still director — pull-ups

```
FORMAT
1 shot · still · 1:1 · instructional Form Index · Mission Winning

SCENE CONTEXT
Clinical pull-up. Prefer TOP of rep (chin over bar). Paper-neutral studio + simple bar.

POSE / EXERCISE LOCK
- Chin clearly above the bar (not dead hang when possible)
- Head fully visible with room above
- Full body hanging head to feet
- Side profile

If model cannot produce chin-over, accept strict dead hang as setup still only.

POSITIVE LOCKS
Pull-up family · full head · full body

NEGATIVES
Cropped head, kipping chaos, multi-person, text, logos.
```
