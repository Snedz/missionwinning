# Loop director — box-jump

```
FORMAT
6s · 1 continuous shot · 1:1 · silent · loopable

ACTIVE REFERENCES
Input still ONLY. Athlete on wooden box.

CAMERA LOCK
Tripod locked. Zero camera motion.

ACTION TIMING
0–1s hold on box · 1–2.5s step down · 2.5–4.5s jump onto box · 4.5–6s settle

PHYSICS
Box fixed. Head always in frame with headroom.

NEGATIVES
Camera move, cropped head, missing box, text, logos.
```
