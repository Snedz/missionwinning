# Loop director — burpees

```
FORMAT
6s · 1 continuous shot · 1:1 · silent · loopable

ACTIVE REFERENCES
Input still ONLY. High plank phase.

CAMERA LOCK
Tripod locked. Zero camera motion.

ACTION TIMING
0–1s plank · 1–2.5s feet to hands · 2.5–3.5s jump · 3.5–5s feet back to plank · 5–6s settle

PHYSICS
Bodyweight. Head always in frame.

NEGATIVES
Camera move, bar, cropped head, text, logos.
```
