# Fair standards, sex, and female athletes

Mission Winning serves **every athlete**. Where performance tools need population standards, we use **biological sex** (male / female) — the same categories used for honest strength ladders, fuel math, and classic youth fitness bands.

## Where sex is used

| Tool | Why sex matters |
|------|-----------------|
| **Fuel / macros / TDEE** | Mifflin–St Jeor BMR has a sex offset |
| **Strength standards** | Separate male and female bodyweight-multiple ladders |
| **Fitness test (PFT)** | Age × sex scoring bands |

Set sex once under **Profile → Sex**, or when a calculator asks. The app should not silently assume male.

## Fair competition

Women’s sport categories exist so female athletes can compete fairly. This product is a **personal coach**, not a sports league — but scoring tools keep **male and female standards separate**. Female standards are first-class product quality, not a niche add-on.

Public principles: in-app **Principles** (`/principles`) and About.

## Cycle-aware coaching (optional)

**Profile → Cycle coaching** (opt-in, off by default):

1. Turn **On** and set **last period start** (+ typical length if not 28 days).
2. Today may show a short educational phase tip; Mission Coach may apply a **small** readiness soft-bias (e.g. menstrual / late luteal).
3. Data stays **on this device** (not cloud-synced in this version).

This is a **heuristic educational model**, not medical diagnosis, hormone treatment, or fertility tracking. Free workout logging is **never** gated by cycle state.

## Not medical care

Educational fitness only. We do not diagnose or treat hormonal conditions. See [Privacy](privacy-and-data.md) and the medical disclaimers on About.
