# Explore places

A quiet map of places you train — not a feed, and not part of logging a set.

**Where:** Account → Explore places, or More → Explore. It is not on Today.

**What you see:** Pins you have tagged (your place-dex) plus a few example public parks. Example parks are a catalog, not a contest — nobody owns them.

**GPS:** Optional. “Show nearby” sorts the list if you allow location. Deny it and you can still roam the list and open a pin in maps.

**Logging:** A set never needs a location. After you finish a session you can tag it on a personal place from Explore.

**Not this:** gym wars, pin takeover, likes, public ranks, or a workout feed.
