# Getting started

Welcome to Mission Winning — a free workout tracker and health companion that works on any phone, anywhere, even offline.

## Install the app (PWA)

1. Open **missionwinning.com** in Chrome, Safari, or Edge.
2. **iPhone:** Share → **Add to Home Screen**.
3. **Android:** Menu → **Install app** or **Add to Home Screen**.
4. Launch from your home screen — it behaves like a native app.

No app store required.

## Free gate

If you see the **gate** (`/private`), the door says **Free**. Public line: **Log a set. Offline.** Support: **No account. No wearable.** Leave an email to **Get notified**, or **Enter with code** if you have an access code. Super Bundle checkout is not open. The logger stays free.

## I-Day (your first mission)

1. Go to **Welcome** or follow prompts after unlock.
2. Complete **I-Day** — a short onboarding that sets your goals and equipment. No account is required.
3. While the site is gated you land on **Train** (`/active`) and start the previewed session. After the public flip you land on **Today** (`/log`) — tap **Start**, then log a set. Today shows this week at a glance — logged days marked, empty days empty. One or two sessions stay a notebook: Wednesday does not invent tomorrow, and empty week days stay empty. Start is still Start. Zero days is fine. An empty rest day on This week can take an optional Fuel restock, easy walk, or scale/tape — Today stays Start workout. If you logged scale or tape twice, that rest day can show last → this. Empty invents nothing.

On **Account**, list your **Home gym kit** (barbell, rack, plates, dumbbells, pull-up bar, floor) so Train picks what you actually have. Free, on this device — no account.

**Track** (`/track`) is the scale / tape log — a number you already have. Optional. Never required to train. Empty invents nothing.

**Learn** (`/learn`) is the free first-success intro — log a set, then Coach from those logs. Other paths and the guidebook sit under Show more. Not a second Today. Opening a live exercise can show a short cue list; a quiet link there opens Learn when you want more than the rack card.

## Your first workout

1. Tap **Train** in the bottom nav (or start from Today).
2. Pick a template from **Builder**, start a blank workout, or tap **Repeat last session** when you already have a completed log (same exercises and last loads). After a session (or from Builder / History), **Save as routine** keeps that list under a name you recognize — **Start** uses it, and Wednesday from your logs does not replace it. A blank notebook is fine — log a set without a plan. No account required — it works offline.
3. Log sets (reps, weight, optional RPE 1–10, RIR, and tempo). None of those ratings are required to save a set. You can type a percent on the set — if you have logged a 1-rep max for that lift, 80% becomes a load; if you have no max, the field stays empty and the app invents nothing. The next-set cite can show that percent next to the target when a known max exists. Opening the live exercise can show a few short setup points — and a still if we already have one. Hide is fine. The full form guide stays behind Info. Tap the movement name to see prior sessions of that lift. Empty invents nothing. On each set you can optionally mark **Warmup**, **Drop**, or **Failure** — never required. Warmup does not count as last time or Wednesday. The next set starts with last time's working load and reps (not a warmup); a first-ever lift is empty — edit the numbers or tap **Last**, and **Log a set** never waits. After a **working** set saves, a tiny note shows whether you added weight or a rep versus last time (or **same**). After a working set that beats a number you already logged (heaviest, most reps at that load, or a best logged 5), a quiet PR shows on that set. A first session invents nothing. Today stays Start workout. If the last work set had an RPE or RIR, that number can show on vs-last, the next-set cite, and Wednesday — empty stays empty; the app does not invent one. After a working set, a skippable line may show the next load or last rest cited from your log — **Skip** is fine and never blocks the next Log set. After a working set, the exercise row may show an **Epley estimated 1RM** — a formula estimate, not a tested max; hide it from the exercise menu. On pull-ups, push-ups, and dips the load field is extra weight on a belt or vest — leave it at **0** to log bodyweight only. The open row matches the movement: weight, bodyweight reps (optional vest), time, or assist. A name you typed stays weight × reps. Empty invents nothing. The app does not add your Track or profile bodyweight into volume. Optional one-line note per exercise (for example “left shoulder felt off”) sits under the sets — it is this session, stays on this device’s log, and is not a feed. You can pin a reminder for that lift (for example “45 degree incline”) that comes back next time you open it. The pin is not History. Rest timer runs automatically. Each lift can remember a **work rest** and a **warmup rest** — bench can rest 3:00 while laterals rest 1:00, and warmup can be shorter than work. Set them on the open exercise. Skip is fine — no penalty. On the set you are logging you can start an optional **EMOM** minute or **AMRAP** window — a clock that is not rest. Empty invents nothing until you start one. Pair two or more exercises (More → Superset w/ next) to run them as one round — rest after the last movement, not at A2. Optional. A saved routine keeps the group. The set table stays. After a working set, **Drop** starts a lighter follow-up on the same exercise with no rest. A set tagged **Drop** does not start the rest timer — the next drop in that series is without rest. A working set still rests. On lunges, dumbbell rows, and other one-sided lifts you can mark **L**, **R**, or **Alt** on the set — optional, still one exercise. On barbell lifts, after you type the load, a skippable plate line may show (for example **45 + 2×45**). The bar defaults to 45 lb or 20 kg and is editable. **Skip** never blocks Log a set. **Add warmups** inserts three simple fractions of that work set (half, two-thirds, three-quarters). Edit or delete any. Warmup still does not count as last time or Wednesday. Free.
4. If the library does not have the movement, type the name in **Add exercise** and use it — unlimited, free, stays on this device. Empty invents nothing. If you logged the same movement under two names, **History** or **Library** can merge them — pick which name to keep, then confirm. This cannot be undone. Empty invents nothing. If a name clutters Add, **Hide this exercise** on Library (or overflow on the live lift) takes it off Add and search. History, PRs, and notes stay. **Unhide** on Library puts it back. Empty invents nothing. If a machine is taken, **Skip this exercise** (hold to confirm) or **Swap** to another movement — this session only. You can also **drag the lifts** (or move them up / down) to a new order — this session only. Tap the name still opens prior sessions of that lift. Garage stand-ins stay the fast pick when we have them; confirm the swap. The week and saved routines stay. Skip is not a fail. Free. Works offline. No account.
5. Finish — your session saves to **History**. You can leave Today, the week glance, Wednesday, or a receipt and come back — Train is the same session. On Train you can **pause the session clock** (tap the elapsed time) so the receipt duration is the time the clock was running — a phone call does not have to count. Leaving Today keeps the set; it does not pause the clock. Today stays Start workout. Finish keeps the sets you logged; leftover empty sets do not count. Victory is a private receipt of the session you just did: sets, load, duration when the clock ran, and vs last time when you have done the same lifts before. Stay on it, screenshot it, or tap **Save receipt** for a copy on this device. There is no public link. A session with no sets has no receipt. A first session has no invented PR. You can add a private note on the live session (Show all) or on the receipt if you have more to record — it stays with that session on this device. From the receipt or History you can **Start this again** — same movements, last loads as targets. Open a finished session from History to **edit the sets you logged**, then **Save**. Confirm before a destructive change. Empty invents nothing. To undo a bogus day, open that session and **Delete this session** — confirm; it cannot be recovered. Other days stay. A live session is not this. If you trained and never opened the app, log that session from History with the date it happened. Empty invents nothing. If an import dumped years into week 1, **Start history from this date** on History folds older days out of the week strip, Coach, and streak — sessions stay. Empty invents nothing. Today stays Start workout. If you skip a planned Coach day, Today offers do it now, skip, or slide — skip is not a fail.

## Sign in (optional — after your first set)

You can log sets with **no account**. Come back on this device and the same local log is still there — a signed-out refresh does not wipe it. Sign in later from Profile if you want the same diary on another device — the sets you already logged here stay yours. Start a session on a laptop and open **Train** on your phone (same account) — it is the same session, no Force Sync tap. Guest sessions stay on this device until you sign in. Restricted health answers (PAR-Q, pregnancy) do not follow a guest onto another account. Signing out of an account on this device does clear local athlete data so the next person does not inherit it.

Sign in with **Google, Apple, Microsoft, Facebook, or email** from Profile (available options depend on your cohort):

- Sync workouts across devices
- Cloud backup for coach plan and journey progress
- School fitness test scores (when your teacher shares a class code)

You can use core logging without an account; data stays on your device until you sign in.

Bring an existing workout CSV (English export) on **Account → Import workout CSV**. Title Case session files and snake_case set files (`title`, `exercise_title`) use the same path. A Hevy measurements export (`date`, `weight_kg`, `fat_percent`) uses that same door and lands as body metrics — it does not replace workouts you already logged. The app shows a preview, then you confirm. You can import more than one file. **Account → Export session CSV** downloads the interchange file; **Export MW CSV** is the native file that re-imports on the same door. Empty history is a header-only file. No account. Works offline.

## What's free vs premium

**Always free:** Workout logger, exercise library, basic nutrition log, calculators, history, benchmarks, and most of Today.

**Premium (Super Bundle):** Mission Coach weekly plan, advanced recipes/programs, guided mind sessions, and deeper guidebook content. See [premium-and-billing.md](premium-and-billing.md).
