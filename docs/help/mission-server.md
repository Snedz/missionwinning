# Messenger (Mission Server)

Rooms on this device when you are a guest. Shared Garage rooms when you are signed in. Not Discord.com, not a feed, not DMs.

**Where:** More → You → **Messenger** (`/server`). Not a primary tab. Today and Train are unchanged — chat never sits on the log path.

**What you get (free):** one Garage, three rooms (`train`, `garage`, `off-topic`), a simple chat window, and presence (Available / Away / Offline). No account required to write locally. Your display name is the name on your profile, or **Athlete** if you have not set one. If you have a Mission ID (`00`–`99`), it shows next to your name.

**Signed in:** the same three rooms are shared with other signed-in athletes. Posts save here first, then sync. Report another person's message if you need to. Signed-in use is for athletes 13+.

**What you do not get:** 1:1 DMs, comments on workouts, a workout feed, likes, public ranks, voice, or Discord.com. Mission Coach does not read the chat. Nudge is a quiet line in the open room — no sound.

If cloud is missing or the table has not been applied yet, the rooms stay local and keep working.
