# Messenger (Mission Server)

Rooms on this device. Not Discord.com, not a feed, not DMs.

**Where:** More → You → **Messenger** (`/server`). Not a primary tab. Today and Train are unchanged — chat never sits on the log path.

**What you get (free):** one Garage, three rooms (`train`, `garage`, `off-topic`), a simple chat window, and presence on this device (Available / Away / Offline). Messages save here. No account required. Your display name is the name on your profile, or **Athlete** if you have not set one. If you have a Mission ID (`00`–`99`), it shows next to your name.

**What you do not get in this version:** 1:1 DMs, comments on workouts, a workout feed, likes, public ranks, voice, or Discord.com. Mission Coach does not read the chat. Nudge is a quiet line in the open room — no sound.

If you sign in and Realtime is turned on, messages may fan out while you are online. If cloud is missing or paused, the rooms stay local and keep working.
