# Garage (Mission Server)

Text rooms on this device. Not Discord.com, not a feed, not DMs.

**Where:** More → You → **Garage** (`/server`). Not a primary tab. Today and Train are unchanged.

**What you get (free):** one Garage server, three text channels (`train`, `garage`, `off-topic`), messages from your call sign (or “Athlete” if you have not set one). They save on this device. No account required.

**What you do not get in this version:** voice, video, direct messages, friend ranking, a feed of workouts, likes, or auto-posts from sets. Mission Coach does not read the chat.

If you sign in and cloud sync is available, messages may fan out while you are online. If cloud is missing, the rooms stay local and keep working.
