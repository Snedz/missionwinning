Yes. The workout tracker, exercise library, program templates, nutrition log, scores, streaks, and leaderboards are free forever, with no account required.

C4 · Zine — C — from scratch
Argues: The opposite pole from A1. Photocopied halftone, newsprint stock, tape, deliberate misregistration, type set too big for its box. Anti-corporate and hand-made — the register of the gym rather than the software.
Type: Archivo 900 Condensed (wdth 62%), set oversized and tight.
Photography: halftone treatment, from the three documentary frames that exist. All eight variants use the same three.
Cost to adopt: Full palette change, and the hardest to hold: hand-made is a house style someone has to keep making. It also collides with the ban list — the halftone is a bitmap texture and the misregistration is a deliberate offset.
