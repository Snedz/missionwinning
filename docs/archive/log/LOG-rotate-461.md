## 2026-08-04 — NL dozen / half-dozen / some (`.446`)

`a dozen eggs` → 12; `half (a) dozen` / `half-dozen` → 6; `some eggs` / `some chicken` → 3 (few band). Half-dozen matcher runs before bare dozen so "half dozen" cannot become 12.

Mutants: drop dozen → 1 egg → red; drop half-dozen before dozen → half dozen becomes 12 → red; drop some → 1× chicken → red.
