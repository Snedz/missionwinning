## 2026-08-08 — Today stops inventing numbers, and its gate goes green (`.602`)

**Three defects on one screen, all the same class: a surface asserting something it has not got.**

**Fabricated body scores.** `MetricsRow` carries a careful em-dash guard and a comment stating the principle — *"a number nobody measured is a worse lie than a zero, because it looks true"* — but the guard asked one question, `sessions > 0`: *has this athlete ever trained*. `HomeTodayDashboard` seeds a literal `{ readiness: 50, strain: 50, recovery: 50 }` until its below-fold imports resolve, so every **returning** athlete passed that test and read three invented figures — captioned "Train smart / Moderate load / Rebuilding", with a coach line derived from them — as measurements of their own body. Precisely the lie the comment describes, arriving down the one road the guard did not watch. Fixed by an explicit `pending` that forces the unmeasured state regardless of session count, threaded from the same `belowFoldReady` flag that decides whether the scores are real.

**"Loading week…" could never stop.** The accordion had `todaysWorkout ? … : "Loading week…"` and **no third branch**, while the four dynamic `import()`s feeding it had **no `.catch`**. A chunk that failed to load left a permanent spinner-in-prose that nothing knew had failed — and, per `.600`, the service worker is gated, so there is no cache to serve that chunk from: a flaky connection produces exactly this, and the two defects compound. Now caught, with an `ErrorState` that is handed an `onAction`, because `ErrorState` renders no retry unless it is given one. The placeholder also never declared `aria-busy`, so it was invisible both to a screen reader and to the a11y suite's `settle()` (`.253`); it does now.

**The hero gate `.596` left red on purpose is green, and the product was never broken.** ⚠️ **Corrected by `.604` — the test was already green; this entry claimed a repair it did not make.** The original claim, kept for the record: that `.first()` selected a hidden *"Cross-pillar Mission Score"* inside `TodaySection`'s collapsed native `<details>` and reported `hidden` forever. Measured on a real Playwright run, `master`'s version **passes** — `.first()` is DOM order and the visible band renders *above* the collapsed section, so it was selecting the visible node all along. What survives: the `data-testid` locator is still the right one, because it names the band rather than matching prose and asserts a real digit, which the old assertion never did. See `.604`.

**Bookkeeping caught two things worth recording.** `i18n:coverage` (cap 0) rejected the three new `todayWeekFailed*` keys until they were catalogued, which is the ratchet working. And `npm run i18n:fill`, reached for to place them, rewrote **42 lines of `src/i18n/packs/es.json`** unrelated to this change — `.252`'s hazard exactly, a fill/export tool producing churn a commit did not ask for. Reverted; the keys were placed by hand. `es` turned out not to need them at all: it spreads `...en`.
