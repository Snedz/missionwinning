# Rotated for .610

## 2026-08-07 — App voice: display type reaches the app (`.594`)

The marketing surfaces got the rebrand's typography; the app got its colours and kept a hand-rolled title no other surface used. `PillarPageHeader` — the header for every pillar screen and info page — set its h1 at an arbitrary `text-[1.65rem]/font-semibold` and its kicker at `text-xs font-medium`, a weight Archivo does not ship. It now speaks `.eyebrow` + `.display-section`, re-inking ~30 screens from one file, and fourteen pages that passed no kicker at all gain one.

**The guard that would have missed it.** `check-display-type` knew a `text-*` utility nullifies a display class and was blind to the weight axis — so a `font-semibold` left beside `.display-section` would have rendered the 800-weight class at 600, silently, in the very edit adopting it (`.212`: a guard keyed to one spelling has only ever tested that spelling). It now flags both axes. **73 synthesized 500/700 weights** swept from page-components behind a new `designWeights` ratchet (page-components 0; components ≤138, may only fall).

**Track recut** onto a `card-section` band of `ScoreNumeral`s — the first real call sites for either, though `card-section` is spec'd as "the default once a screen is recut". Learn drops emoji for lucide (the data schema keeps its emoji field; Android reads it).

**Two red actions on master, found by trying to ship past them.** `/move` measured 1 against a cap of 0 and `/mind` 2 against 1 — and reverting my own Mind/Move edits did not move the numbers, so I built `origin/master` in a worktree and ran the spec there: **identical counts on a clean tip.** The cause is the collection filter chips both screens gained, drawn as `border-primary bg-primary text-primary-foreground`; the ratchet reads computed colour, and a filled poster-red chip is a red action however it is spelled. The repo had already answered this — `/programs`' own cap row reads *"Was 2 — both were selected filter chips. `variant="selected"` fixed it"* — so the chips move to `is-active-tab`, the tint-plus-2px-rule treatment `.240` settled on for "what does selected look like". A selection is not an action. `/move` back to 0, `/mind` to 1, 16/16 green.

**Mind/Move disclosure unification was tried and reverted, by the ratchet.** Both screens carry two disclosure idioms — a native `details/summary` and a `useState` + `ChevronDown` button — and collapsing them onto one looked like free consistency. It is not: `<details>` keeps its collapsed content in the DOM, and the locked previews behind that second disclosure contain an `UnlockButton`. `/mind` went 1→2 red actions and `/move` 0→1, measured, not guessed. The cap is the more valuable invariant, and idiom consistency is not worth spending it — reverted to the state-driven version on both. Anyone retrying this must render the preview conditionally, which is the state the change was trying to delete.

**`/experience` retired** — 729 lines of emerald hex, `oklch()` swatches, retired `--brass` and 12 non-zero radii, invisible for a full rebrand cycle because `check-design-system` walked `.tsx`/`.ts` plus one hand-named stylesheet. The checker now walks `.css`, catches `oklch()` literals and allows `font-family: inherit`; the extension lands in the same commit as the deletion, so the check is green at every commit.

**Found while shipping: `check-build-label` could not read its own input.** Its regex accepted `'…'` only, and a formatter pass had rewritten `buildInfo.ts` to double quotes — so the step died on *"Could not read APP_BUILD_LABEL"* instead of comparing labels, and had been unable to answer its question for however long the quotes have been that way. Widened to both quote styles: how the constant is quoted is a formatter's business, not the guard's. `.220` again — a check stops asking without anyone deciding to stop it.

Mutants (2 killed + 2 live): font-medium reintroduced in page-components → designWeights red; `.579` rotation verified by the LOG budget test; live — font-semibold planted beside `.display-section` → check-display-type red (reverted); hex planted in `gate.css` → css-walk red (reverted).
