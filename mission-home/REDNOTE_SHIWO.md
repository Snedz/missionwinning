# RedNote / 适我主义

Xiaohongshu (RedNote) is the **research surface** for these notes. It is not a shop and not a checkout.

**适我主义** is Xiaohongshu’s 2026 living-trend language: the house fits the inhabitant’s real habits. Public coverage (April 2026 living-trend release, *家的100个适我主义提案*) named 去家务化, 动线, 容乱区, and 家是我的能量场 as the same family — lower housework, allow a closed mess, treat the home as an energy field. Steal the **patterns**. Skip the photo-first copies and any cart.

Queries live in [SEARCH_SEEDS.md](SEARCH_SEEDS.md). Rooms that apply them live in [README.md](README.md).

## 适我主义

The house answers the people who walk it. Not a second style name. Not “no trend” as a brand.

| STEAL | SKIP |
|-------|------|
| Plan from actual morning / return / sleep paths | Copying a photographed apartment that is not this loft |
| Materials that may age (see [MATERIALS.md](MATERIALS.md)) | A style catalog pasted onto industrial bones |
| One calm visual field + closed storage | Perfection that only holds for a still |

## 去家务化动线

Circulation that **deletes extra housework steps**. Entry dirt-lock (shoe closet). Kitchen reach (fuel wall + island). Laundry hand-off if a stack exists. The 2026 notes also talk 适懒化: design so the honest lazy path is the clean path.

| STEAL | SKIP |
|-------|------|
| Shoes / bag / coat die at the door | Open pretty racks in the living field |
| Island and fuel wall in one reach | A coffee station on every level “for the photo” |
| Trash and recycle on the cook’s step (不弯腰 if the height is honest) | Hiding bins so far that bags sit on the island |
| 无拖延症动线: the next object is where the last action ends | A pretty loop that adds steps |

## 容乱区

A **closed volume** that may look lived-in so the visual field can stay calm. Sliding wardrobe is the clothes one. A door on the fuel wall is the coffee one. The point is permission, not a second messy room that leaks.

| STEAL | SKIP |
|-------|------|
| Full-height flush planes | Open shelves as “organized clutter” for stills |
| One motion to hide | Leaving the plane open as display |
| Patina on soapstone / oak (mess at material level) | A showroom shine that punishes use |

## 能量场

Morning light. Warm kelvin. Ritual objects. Less visual noise. Xiaohongshu’s “家是我的能量场” line is mood + light + fewer drains — not a crystal SKU.

| STEAL | SKIP |
|-------|------|
| 2700K as the evening field; cooler only on a task | Gallery cool-white on the stair and island |
| Limewash or a matte plane that softens bounce | Gloss walls that turn every object into glare |
| Coffee + book + one chair that is used | Accessory piles sold as “energy” |

## 早C岛台

The island as the **morning start station**. C = coffee / 晨间 C 位 — the day’s first seat. Pair with the coffee fuel wall. Not a second unused sink for photographs.

| STEAL | SKIP |
|-------|------|
| Kettle outlet on the fuel-wall side | A show sink that never sees a glass |
| One seating side; loop around if the plan allows | Island parked in the only walk |
| A top that may mark | Waterfall film that wants a cloth after every cup |

## Supporting notes (same family)

These are not extra rooms. They are the same 去家务化 family if they earn a line:

- **适懒化** — the honest lazy path is the clean path (entry, trash, laundry).
- **不弯腰垃圾桶** — bin height on the cook’s step; skip if it becomes a gadget wall.
- **无拖延症动线** — the next object waits where the last action ends (bath towel, dirty clothes, keys).
