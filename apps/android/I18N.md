# Android i18n — Mission Winning (Phase 16 foundation)

## Goals

- **Global free core** (vision.md): EN first, then ES / PT for reach. French is not offered — France is founder-excluded.
- Product chrome and CTAs localizable without rewriting Compose  
- Coach engine strings stay server/seed-driven (not forked in Kotlin)

## Locales

| Code | Status |
|------|--------|
| `en` (default) | Source of truth |
| `es` | Chrome strings (designsystem) |
| `pt` | Chrome strings |

Per-app language: `app/src/main/res/xml/locales_config.xml` (Play in-app language picker on Android 13+).

## Where strings live

| Module | Role |
|--------|------|
| `:core:designsystem` `res/values*/strings.xml` | Shared chrome: tabs, heroes, primary CTAs |
| `:app` `res/values*/strings.xml` | Notifications, widgets, app name |
| `:wear` | Watch strings |

**Convention:** new user-facing copy → `mw_*` key in designsystem EN first, then mirror es/pt.

## Usage in Compose

```kotlin
import androidx.compose.ui.res.stringResource
import com.missionwinning.core.designsystem.R

Text(stringResource(R.string.mw_hero_today))
MwPrimaryButton(
    text = stringResource(R.string.mw_start_workout),
    ...
)
```

Hardcoded English remains in older screens; migrate opportunistically when touching a file.

## Do not

- Port full web i18n JSON into Android  
- Localize exercise catalog names without a product decision (IDs stay stable)  
- Gate free logger features by locale  

## Expanding a language

1. Add `<locale android:name="xx" />` to `locales_config.xml`  
2. Create `values-xx/strings.xml` under designsystem (+ app if needed)  
3. Translate all `mw_*` keys  
4. Smoke: Settings → App language → app relaunches with new chrome
