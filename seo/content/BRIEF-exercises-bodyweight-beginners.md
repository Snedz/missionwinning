## Spoke exercise pages (pattern for beginners cluster)

Reuse `/exercises/*` template; ensure beginners cluster spokes include:

1. **What it is** (1–2 sentences)  
2. **Setup / equipment** (none / bar / bench)  
3. **Step-by-step**  
4. **Regressions → progressions** (link related exercises in library)  
5. **Programming cue** (sets/reps beginner range — not a full plan)  
6. **CTA:** Track this exercise free → `/welcome`  
7. **Related:** link hub + guide pillar + relevant calculator only if natural (e.g. strength curiosity → `/calculators/1rm` or standards — don’t force)

### Priority spokes to QA first

Push-up, squat, inverted row, plank, hang, lunge, glute bridge, hollow hold — match hub “Start here.”
